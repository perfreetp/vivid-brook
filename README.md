# 机器人野外测试场 · 过程式路面与障碍生成编辑器

Vue 3 + TypeScript + WebGPU 的过程式测试场地生成/编辑/质检系统。一片场地 **40m × 40m**，
64×64 格网（0.625m/格），划分为 **16×16 = 256 个区块**（每块 2.5m、5×5 顶点、32 三角面）。

## 启动

```bash
npm install
npm run dev        # http://127.0.0.1:5173
npm run build      # 生产构建
npm run typecheck  # 类型检查
```

## 四个界面

| 路由 | 界面 | 职责 |
|---|---|---|
| `/#/orders` | 需求单 | 前台按客户测试需求建单，录 seed 与五参数，派单给建模员 |
| `/#/editor/:orderId?` | 生成编辑 | 过程式生成、分块锁定/解锁、刷高/削平/挖沟、线框、导出、提交质检 |
| `/#/qc` | 质检 | 拿**同一 seed 同一组参数**独立重跑，逐区块哈希比对，一致通过、不一致打回 |
| `/#/dashboard` | 看板 | 各人完成单量、在办、返工率、累计返工、状态分布 |

右上角可切换当前身份（前台 / 建模员 / 建模员 / 质检），按钮权限随角色变化。

## 五个生成参数

- **坡度档位** 0–5 档 → 0% / 5% / 10% / 15% / 20% / 25%（坡度带 z=0–8m）
- **台阶高度** 0–0.4m，0 关闭（台阶带 z=8–16m）
- **碎石密度** 0–1，抖动网格确定性布石（碎石带 z=16–24m）
- **沟槽宽度** 0–2m，0 关闭，沟深 0.6m（沟槽带 z=24–32m）
- **涉水深度** 0–1.2m，0 关闭，盆地下凹 + 半透明水面（涉水带 z=32–40m）

## 关键设计

### 确定性（质检一致性的基础）
- 全部随机来自整数 hash（`hash32`/`valueNoise`/`fbm`/`mulberry32`），**不使用 `Math.random`/`Date.now` 参与地形计算**；
- 高度是 `(seed, params, x, z)` 的纯函数，按**世界坐标**生成，跨区块边界天然连续，分块重算无裂缝；
- 同 seed + 同参数逐点结果完全一致，单元验证与端到端测试均已覆盖。

### 增量重算
- 每个区块带特征标签（slope/step/gravel/trench/water）；
- 改某个参数只重算对应特征带内的**解锁区块**（实测改沟槽宽度约重算 80/256 块、个位数毫秒）；
- 手动刷过的区域自动锁定，重生成时跳过；锁定区边界按距离权重做 2 格指数过渡，保证 C0 连续。

### 手动编辑
- 拖框锁定 / 拖框解锁（按区块对齐）；
- 刷高、削平（向落笔高度收敛）、挖沟三种塑形笔刷，半径 3 格、带余弦衰减；
- 单块可解锁并「丢弃手修恢复」为过程式结果。

### 渲染
- **WebGPU**：高度走 storage buffer，每顶点着色器取高并有限差分算法线；fill/line 两套管线，
  一键切线框核对坡度与台阶；区块格网、特征带染色、锁定橙框、悬停/选中高亮、涉水半透明水面；
- 浏览器不支持 WebGPU 时自动降级 **Canvas2D 俯视热力图**，编辑/锁定/塑形/质检功能不受影响。

### 导出（仿真用）
- `*_h16.raw` + `*_h16.meta.json`：65×65、uint16-LE 高度图，含尺寸/量化范围元数据；
- `*_preview.png`：8bit 灰度预览；
- `*.obj`：4225 顶点、8192 三角面，y 向上、场地中心归零。

### 质检口径
- 提交时保存毫米量化快照（高度 + 锁定态 + 区块元数据 + checksum）；
- 质检端用订单 seed/参数独立重算，按 **1mm 量化**逐区块 FNV 哈希比对；
- **锁定（手修）区块不参与自动比对**，需人工确认；任何解锁块哈希不一致即打回，返工次数 +1 并进入看板统计。
