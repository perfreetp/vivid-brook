# 河道地形曲面与堤线建模台

面向水利测绘院的河道三维建模作业平台：导入断面高程点与河道边界生成河床地形曲面，
作业员对河道中心线与堤顶线进行样条控制点增删拖拽，实时分析曲率并对突变段着色提醒，
岸线等距偏移生成管理范围平行线，横断面剖切、堤坡测地线展开，以及项目建档—加工—版本比对—报告归档的完整档案流程。

纯前端实现：**原生 TypeScript + Web Components + three.js**，无 UI 框架；构建工具 Vite，
档案数据保存在浏览器 IndexedDB，无需后端服务即可单机作业。

## 启动

```bash
npm install
npm run dev        # 开发模式 http://localhost:5173
npm run build      # 类型检查 + 生产构建（输出 dist/）
npm run preview    # 预览生产构建
```

打开后点击左侧 **① 数据导入 → 载入示例河段** 即可体验完整流程（2.4 km 蜿蜒河道，533 个断面高程点）。
`public/samples/` 下提供可下载的高程点/边界 CSV 样例。

## 功能与操作流程

| 序号 | 模块 | 能力 |
| --- | --- | --- |
| ① | 数据导入 | 断面高程点 CSV（x,y,z，允许表头/点号列）、河道边界 CSV（名称,x,y，自动分组）、示例数据 |
| ② | 堤线样条编辑 | 中心线/左右堤顶线三条向心 Catmull-Rom 样条；拖拽黄球移动控制点、双击样条就近插点、Delete 删点、撤销/重做；里程-曲率/曲率半径双轴曲线图，超阈值段红色提醒 |
| ③ | 管理范围偏移 | 堤顶线向河道外侧等距偏移；距离可调；角部圆角（圆弧分段）或尖角（miter 斜接，超限自动回退斜切） |
| ④ | 地形曲面 | 最近邻 IDW 插值 + 边界多边形裁剪的规则栅格三角网；高程/坡度/曲率三种顶点着色切换；分辨率与 IDW 幂可调 |
| ⑤ | 横断面剖切 | 沿中心线任意里程拉横断面，三维视口显示剖切位置，面板绘制地形起伏剖面曲线与高程范围 |
| ⑥ | 测地线展开 | 选中堤坡与里程区间，三维三角条带按实长逐排保距铺到平面；成果图标注展开面积、平均坡长、堤顶/坡脚长、等高程线 |
| ⑦ | 档案加工 | 自动编号建档（SL-年份-顺序号）→ 加工归档生成版本快照与 HTML 成果报告 → 任意两版本指标比对 → 按项目编号/河段/建模日期检索 |

### 三维视口交互

- 左键拖动旋转、滚轮缩放；**拖拽黄色球**移动控制点（rAF 合并刷新，单次拖拽合并为一条撤销记录）
- 在样条附近**双击**插入控制点；**Delete/Backspace** 删除当前线末点（至少保留 2 点）
- 顶部工具条：撤销 / 重做 / 视图适配

## 关键算法

- `src/math/spline.ts` — 向心 Catmull-Rom 采样、弧长参数化、差分法曲率 κ=|x′y″−y′x″|/(x′²+y′²)^1.5 与曲率半径，滑动平均抑抖
- `src/math/offset.ts` — 开放折线等距偏移，逐顶点法线求交；凸角处圆角圆弧 / miter 尖角（含斜接限制），凹角法线交点
- `src/math/terrain.ts` — 最近 K 点 IDW 栅格插值、射线法边界裁剪、中心差分坡度、拉普拉斯算子地形曲率、双线性栅格采样
- `src/math/unfold.ts` — 坡脚沿法线坡度变化探测；三角条带两圆交会保距展开（所有边长取三维实长，展开面积=坡面实测面积）；条带内等高程线插值
- `src/data/archive.ts` — IndexedDB 建档/版本/检索，版本指标 diff

## 目录结构

```
src/
├─ math/        样条曲率、等距偏移、地形栅格、色带、测地线展开
├─ state/       类型定义、全局 store（订阅广播 + 堤线编辑撤销重做）
├─ data/        CSV 解析、示例数据、IndexedDB 档案、版本比对、HTML 报告
├─ three/       SceneManager：渲染、控制点射线拾取与拖拽、断面/展开预览
├─ components/  9 个 Web Components（Shadow DOM，可折叠面板）
└─ main.ts      组件注册与流程装配
scripts/smoke-cdp.mjs   无头 Chrome CDP 端到端冒烟测试（10 项断言）
```

```csv

```

## 说明与限制

- 坐标按工程平面坐标（米）处理，未内置投影换算；如源数据为经纬度需先投影。
- 档案存于浏览器本地 IndexedDB（库名 `river-modeler-db`），清浏览器数据会删除档案；重要成果请用报告下载与项目导出留存。
- 栅格为规则网格 IDW，适用于断面测点布设场景；海量点云（十万级以上）建议先抽稀或后续替换为分块索引。
