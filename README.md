# 硅胶指腹曲面建模与展开下料工具

面向机器人柔性夹爪打样组:Svelte + WebGPU 实现的指腹截面建模、曲面预览、等距偏移内衬、展开下料与订单流程管理。

## 运行

```bash
npm install
npm run dev      # 开发
npm run build    # 构建(输出 dist/)
```

浏览器需支持 WebGPU(Chrome/Edge 113+);不支持时自动回退 CPU 线框预览。

## 功能

**曲面建模**
- 截面样条:控制点 + 切线手柄拖拽,加点模式点击曲线插点,锚点权重(有理贝塞尔)调节
- 实时曲率梳,相邻采样曲率差超阈值处标红提示
- WebGPU 顶点着色器内做曲面细分(截面样条段数据走 storage buffer),曲率热力实时着色;支持扫掠长度、末端变截面

**展开下料**
- 按指定间距等距偏移生成内衬轮廓;偏移自交时报告干涉发生在第几段(采样区间标红)
- 按缝合边位置切开摊平,K 因子 + 料厚做中性层折弯补偿
- 采样密度可调;输出曲面面积、展开面积、下料尺寸(含缝份),可导出 SVG 下料图

**订单项目**
- 客户:建单(标题、截止时间、多条指腹条目、关联设计、数量)
- 制作员:按条目开始制作 → 载入设计到建模页 → 提交审核
- 主管:审核通过 / 退回(返工次数 +1、记备注);全部通过后打包交付
- 订单超期标红,数据存 localStorage

## 目录

```
src/lib/geometry/   样条、偏移干涉、扫掠曲面、展开补偿(纯几何,可单测)
src/lib/webgpu/     WebGPU 渲染器(WGSL 曲面细分 + 曲率着色)
src/lib/components/ 样条编辑器 / 曲面视图 / 展开下料 / 订单视图
```
