# 蓝湾水上乐园 · 园区总图与检修派单系统

React 18 + three.js(正交相机俯视渲染)+ zustand。测绘底图为内置确定性模拟数据(4 片区 / 9 池体 / 约 3000+ 构件 / 管线 / 绿化 / 警戒线)。

## 运行

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 产物在 dist/
```

## 功能对照

| 需求 | 实现 |
| --- | --- |
| 全园/片区/池体三级视口 | 按可视宽度自动切换 LOD(>700m 全园 / 180–700m 片区 / <180m 池体),顶栏面包屑可直达 |
| 全园只画点阵+池体轮廓 | 全园级仅 `THREE.Points` 点阵(单次 draw call)+ 池体轮廓线 |
| 片区级出构件图标和编号 | 每类构件一个 `InstancedMesh`,DOM 标注层显示编号 |
| 池体级喷淋头朝向角度 | 池体级叠加朝向箭头实例 + 编号与角度标注 |
| 图层树 | 设备/管线/绿化/警戒线独立开关,设备层可按 5 类构件再开关,管线带管径图例 |
| 60 帧平移缩放 | 按需重绘(静止不渲染)、阻尼动画、实例化渲染 |
| 点选高亮+气泡 | 射线拾取实例,描边高亮,气泡显示编号/所属池体/上次检修日期 |
| 框选整组改状态 | Shift+拖拽框选,批量标记正常/待修/停用、整组生成派工单 |
| 管线按管径分色、交叉断开 | DN50/75/110/160 四色;数据层预计算交叉点,下层位管线自动留缺口 |
| 标注重叠自动抽稀 | 屏幕空间网格占位去重,选中构件标注优先 |
| 编号直达 | 侧栏输入编号(支持模糊)直接飞到构件并选中 |
| 故障→派单→维修→质检→打回 | 工单状态机:待派单→待处理→待质检→已完成,不合格打回计入返工 |
| 看板 | 各师傅派单数/完成量/在途/提交/打回/返工率 |
| 导出视口平面图 | 顶栏按钮导出 PNG(含标题栏、图例、视口信息),供园务会使用 |

## 操作

- 滚轮缩放(以光标为锚点)、拖拽平移、双击放大
- 全园级别点击池体 → 飞入所属片区
- Shift+拖拽 → 框选;点击构件 → 气泡
