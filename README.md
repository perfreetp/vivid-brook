# 实验室安全设施分层渲染与识图考核平台

面向高校实验室安全培训的 Web 平台：把整栋实验楼的气瓶柜、通风橱、洗眼器、管线按楼层与专业分层绘制在 Babylon.js 正交相机平面图上，支持缩放聚合、视口裁剪、图层开关、点选/框选、编号搜索，并提供老师出题、学员识图作答、系统自动判分与老师复核的完整考核闭环。

## 技术栈

- **SolidJS 1.9** + TypeScript（响应式 UI 与状态管理）
- **Babylon.js 7.54**（WebGL2 正交相机、ThinInstance 批量渲染、DynamicTexture 图标）
- **Vite 6** 构建，无后端，数据与试卷通过 `localStorage` 持久化

## 模拟数据

`src/data/generator.ts` 用确定性伪随机生成 1 栋 8 层、384 个房间、**3110 个设施**的实验楼：

| 类型 | 编号前缀 | 图层分组 |
| --- | --- | --- |
| 气瓶柜 | GC | 气防 |
| 通风橱 | FH | 危化品 |
| 洗眼器 | EW | 消防 |
| 管线 | PL | 水电 |

同一种子每次生成结果一致，保证考核答案稳定。通风橱与配套管线通过 `linkedCode` 建立同编号关联。

## 核心实现

### 渲染（`src/engine/mapEngine.ts`）

- **正交相机**：`ORTHOGRAPHIC_CAMERA` 顶视平面图，滚轮以光标为锚点缩放，拖拽平移，双击放大。
- **视口裁剪**：`SpatialIndex`（`src/engine/spatial.ts`）按 12m 网格分桶，每帧只查询当前楼层、开启图层、视口矩形内的要素，数千设施下单帧只重建可见部分。
- **三级渲染**：
  - 楼栋级（半高 ≥42m）：同楼层同类型按 16m 网格 **聚合为一个块并显示数量**；
  - 楼层级：单图标；
  - 房间级（半高 ≤16m）：单图标 **+ 设备编号标签**。
- **ThinInstance**：每类设施一个 mesh、一个 matrix buffer，切换楼层/图层/视口只换 buffer，不销毁重建资源，DOM 标签走对象池，因此图层开关后视口重排**不闪烁**。
- **管线**：按折线路径动态生成缩放+旋转的实例段。
- **叠放拾取**：同位置多要素按 `TYPE_PRIORITY`（洗眼器 > 气瓶柜 > 通风橱 > 管线）+ 距离排序命中。
- **搜索飞行**：`flyTo` 用缓动动画把相机从当前位置逐级放大到目标房间。

### 交互

- 点选弹出信息卡，黄色高亮环标记同编号关联设备；
- Shift 拖拽或工具栏进入框选模式，批量统计选中数量并按四个图层组、四个类型分类汇总；
- 底部 Canvas 小地图实时显示楼层设施分布与当前视口框，点击可跳转。

### 考核（`src/state/store.ts` + `src/components/QuizPanel.tsx`）

1. **老师**指定设施类型、数量、楼层生成识图题（含随机标准答案）；
2. **学员**在图上逐一点选作答，开始题目自动切到对应楼层，再次点选可取消；
3. 提交时系统按**坐标（设施 id 即同一坐标）+ 类型**双匹配自动初判；
4. 老师在复核面板逐题查看学员点选与标准答案对比，调整分数、填写备注；
5. 成绩与错题数按**班级汇总**，区分自动初判分与复核终评分、待复核/已复核状态。

试卷、作答、复核结果均持久化在 `localStorage`（键 `lsmp-papers-v1`）。
