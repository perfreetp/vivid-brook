# 浇注系统平面布置编辑台

面向注塑模具厂的浇注系统 2D 矢量编辑 + 3D 校核工具。

## 技术栈

- **SolidJS** — 界面与响应式状态
- **Canvas 2D** — 编辑画布
- **Babylon.js** — 三维预览(轮廓按流道高度拉伸)
- **polygon-clipping** — 多边形布尔运算(并/差/交)

## 运行

```bash
npm install
npm run dev    # http://127.0.0.1:5173
npm run build  # 产物在 dist/
```

## 功能对照

| 需求 | 实现 |
| --- | --- |
| 符号库拖入主流道/分流道/扇形浇口/顶针/冷却水路 | 左侧图元库 HTML5 拖放到画布(另有镶件) |
| 模架螺孔网格吸附 | 可调网格距(默认 25mm),落点自动吸附 |
| 端点/中点吸附 | 拖动时绿色指示圈,可分别开关 |
| 沿边等距排列 | 工具栏「沿边等距排列」:选中图元后点目标边 |
| 对齐参考线 | 拖动时与其他图元锚点 x/y 对齐,品红虚线 |
| 并集/差集/交集 | 工具栏布尔组,基于 polygon-clipping |
| 搭接流道合成一整条 | 「合成整条流道」= 流道类图元并集 |
| 镶件挖让位孔保留外轮廓 | 「镶件挖让位孔」:差集,原镶件保留为隐藏参考 |
| 布尔结果可拆开再改 | 「拆开布尔结果」恢复来源图元 |
| 镜像/环形阵列 | 多选后工具栏操作,阵列可设数量与总角度 |
| 撤销/重做 50 步 + 任意历史节点 | Ctrl+Z/Y,右侧历史列表点击跳转 |
| Babylon 3D 预览 | 按流道高度拉伸,镶件/水路半透明 |
| 脱模方向干涉检查 | 顶针/水路与流道投影重叠自动标红并列出 |
| 3D 面片反查 2D 图元 | 点击网格面片即选中对应 2D 图元 |
| 导出 SVG | 毫米单位、evenodd 填充(孔洞正确) |
| 版本管理 | 「提交当前方案为新版本」 |
| 画布打点批注 + 逐条回复 | 批注模式下点击画布,右侧面板回复/标记处理 |
| 双版本并排差异 | 选择版本 A/B,新增/删除/修改分色高亮 |

## 操作

- 空格+拖动 / 中键:平移;滚轮:缩放
- 点击选择,Shift 多选,空白拖动框选
- 方向键微调(Shift ×10),Del 删除,Esc 取消
- 状态自动保存到 localStorage
