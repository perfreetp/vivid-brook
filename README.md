# 历史街区日照与夜间照明校核预览台

基于 SolidJS + PixiJS 的二维布光预览与校核工具, 面向历史街区保护规划的日照与夜间照明审查。

## 运行

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 产物在 dist/
```

## 功能

- **场景绘制**: 手绘或导入(JSON)建筑轮廓并填写层数(层高 3m); 画街坊边界用于分区统计
- **三种光源**: 路灯 / 庭院灯 / 洗墙灯, 均可调挂高、半径、色温(1800–6500K)、强度, 可开关、拖动
- **日照计算**: 时间滑块 9:00–21:00, 按夏至/冬至与纬度计算太阳高度角/方位角, 建筑按轮廓与高度投射阴影
- **夜间照明**: 光源到 1m 地面网格逐格步进做可见性(建筑遮挡), 阴影边缘按光源尺寸做半影柔化; 多光源按色温转 RGB 加权叠加, 再经曝光与伽马校正输出效果图
- **照度热力图**: 对数色带, 放大后逐格显示照度数值; 低于 20lx 的格子自动标红, 统计暗区块数与面积
- **图层开关**: 建筑 / 光斑 / 热力图 / 1m 网格(另有街坊边界、批注、格值)
- **审查流程**: 草稿 → 送审 → 公示; 审查人可填意见退回或通过; 公示状态只读, 公众可在地图上标点批注
- **统计导出**: 各街坊平均照度与暗区占比; 导出效果图 PNG、照度统计 CSV、方案 JSON

## 计算模型说明

- 太阳位置: 简化赤纬模型(±23.44°), 正午 12:00, 直射水平照度 ≈ 100klx·sin(高度角), 天空漫射处处可得
- 人工光: 点光源余弦三次方衰减 `E = I·h / (h²+d²)^1.5`, 半径外缘 20% 平滑截止
- 遮挡: 光源至网格点连线步进采样, 光线高度低于建筑高度即被遮挡; 可见性图按光源尺寸盒式模糊得半影
- 暗区: 照度 < 20lx 的四连通域, 逐块统计面积与中心位置
