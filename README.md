# 笔杆雕刻纹样编辑与素材批次放行工具

面向毛笔厂笔杆激光雕刻工序的内部工具：在**笔杆圆周展开图**上用贝塞尔曲线描绘雕刻纹样，做布尔运算与窄缝校验，并对供应商批次素材执行自动检查、逐条复核与整批放行。

技术栈：**Vue 3（Composition API）+ 原生 SVG 渲染 + D3（d3-drag / d3-selection）交互 + paper.js 布尔运算引擎 + Vite**。

## 启动

```bash
npm install
npm run dev      # 开发服务器（默认 http://127.0.0.1:5173）
npm run build    # 生产构建
npm test         # 17 项核心逻辑冒烟测试
```

## 功能与需求对照

| 需求 | 实现位置 / 说明 |
| --- | --- |
| 圆周展开画布，按直径换算周长 | `editor/geometry.js#circumference`（π×直径）；左栏改直径即时重算，SVG `viewBox` 宽度即周长 |
| 环向等分参考线 | `CanvasStage.vue` 按 `周长 ÷ 等分数` 绘制等分竖线（含 0/周长拼缝虚线）与编号，另含轴向网格、十字中心线 |
| 贝塞尔描路径、加节点、断开、闭合 | 钢笔工具（三次贝塞尔手柄）；加节点工具在边上按 de Casteljau 精确拆分；断开支持闭合路径开口与开放路径断成两条；一键闭合 |
| 两条路径并/差/交集 | `editor/paper-boolean.js`（paper.js），仅允许两条闭合路径，差集按选择顺序 A−B；原路径隐藏保留，结果携带运算履历 |
| <0.3mm 窄缝自动标红 | `geometry.js#findNarrowGaps`（空间分桶加速的线段间距检测），阈值可调；画布红圈标注、路径描边变红、右栏列明细、导出 SVG 同步标红 |
| 节点拖动吸附 | 吸附网格交点、中心线、拼缝边、其它路径端点，吸附半径可调，画面显示绿色吸附提示 |
| 环向阵列三份且首尾相接 | 周长 ÷3 等距复刻两份副本，并对 x=0 / x=周长 拼缝端点做 y 向匹配校验，错位弹警告 |
| 撤销/重做 ≥50 步 | `editor/history.js` 上限 100 步，拖拽类连续操作自动合并为单步；Ctrl+Z / Ctrl+Y |
| 导出 SVG 保留图层分组与原始路径数据 | `editor/svg-export.js`：每层一个 `inkscape:layer` 的 `<g>`，每条 path 带 `data-original-nodes` 原始节点与 `data-source` 运算履历 |
| 批次自动检查三级分类 | `editor/batch.js`：按线宽（<0.3 退回 / <0.5 警告）、断点数、窄缝指标分为 合格 / 警告 / 退回 |
| 复核员逐条确认或驳回 | 驳回**强制填写原因**；可撤回重审；署名记录与时间戳 |
| 整批处理完才能放行 | 存在任一待复核项时放行按钮禁用；放行后可导出含确认素材 SVG 的放行单 |
| 退回带原因回供应商 | 一键导出退回清单 JSON，含自动检查结论 + 复核驳回原因 + 复核人 |

## 操作速查

- `V` 选择 ｜ `P` 钢笔 ｜ `A` 加节点 ｜ `J` 闭合 ｜ `K` 断开 ｜ `Del` 删除 ｜ `Enter`/双击 结束钢笔 ｜ `Esc` 取消
- 钢笔：单击加节点，按住 Shift 单击加光滑节点，拖动节点上的蓝色手柄调贝塞尔曲率
- 布尔：按住 Shift 依次点两条闭合路径（顺序即 A、B），再点 ∪ / − / ∩
- 批次页点「载入示例批次」可看到覆盖三级判定的 6 条演示素材

## 目录结构

```
src/
├── editor/
│   ├── geometry.js      # 周长、贝塞尔展平、窄缝检测、吸附、边上加点
│   ├── model.js         # 文档/图层/路径节点模型、环向阵列、拼缝校验
│   ├── paper-boolean.js # paper.js 布尔运算封装
│   ├── history.js       # 100 步撤销重做栈（合并键）
│   ├── store.js         # 编辑器全局状态与全部编辑操作
│   ├── batch.js         # 批次自动检查、复核、放行、退回清单
│   └── svg-export.js    # 带图层分组与原始数据的 SVG 导出
├── components/
│   ├── CanvasStage.vue  # SVG 画布 + D3 拖拽交互
│   ├── LeftPanel.vue    # 笔杆参数/参考线/图层/路径清单
│   ├── RightPanel.vue   # 历史/属性/布尔/阵列/窄缝/导出
│   └── BatchReview.vue  # 批次放行台
└── test/smoke.mjs       # 核心逻辑测试（npm test）
```

所有尺寸内部统一以 **mm** 为单位，SVG 导出宽高带 `mm` 单位，可直接交激光雕刻排版软件读取。
