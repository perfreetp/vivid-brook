# 机器人剧场 · 走位与地面标线矢量编辑器

面向剧场编排师的机器人走位编排工具。Vue 3 + PixiJS v8 实现，数据持久化在浏览器 localStorage。

## 启动

```bash
npm install
npm run dev        # http://localhost:5180
npm test           # 47 项逻辑测试（布尔/几何/吸附/SVG/排期/撤销）
npm run build      # 生产构建
```

## 四个界面

| 界面 | 能力 |
| --- | --- |
| 剧目列表 | 建剧目档案（场地/日期/时段/舞台尺寸），打开、删除 |
| 走位画布 | 矢量编辑主界面，见下 |
| 素材库 | 机器人型号增删改（半径/速度/载重/标识色），持久化 |
| 后台 | 排期提交、冲突拦截、场次与编排时长统计 |

## 走位画布能力

- **机器人投放**：左侧素材托盘点击或 HTML5 拖放到画布落点
- **图形工具**：矩形（候场区）、圆、多边形（单击加点、双击闭合）、自绘路径（节点 + 曲率手柄、双击结束）
- **节点编辑**：节点工具下拖动锚点、拖曲率手柄（Shift 解除对称联动）；双击路径边线插入节点
- **布尔运算**：选两个形状做并集 ∪ / 交集 ∩ / 差集 −，结果保留圆角元数据并自动合并 2px 内重叠节点（Greiner–Hormann 实现，见 `src/lib/boolean.js`）
- **四种吸附**：网格 / 端点 / 中点 / 等距，12px 阈值内显示红色（对齐）或紫色（等距）参考线
- **一键镜像**：以舞台垂直中线为轴镜像选中图形，路径曲率手柄同步翻转
- **撤销/重做**：Ctrl+Z / Ctrl+Shift+Z，每剧目独立历史栈（最多 60 步），只回退图形内容、不动层序
- **三层固定层序**：舞台层 → 路径标线层 → 机器人位层，层序来自数据字段 `layer`，撤销重做不影响
- **SVG 导出**：按三层 `<g>` 分组输出干净 SVG，节拍/演员写入 `data-beat` / `data-actor`
- **视口**：滚轮缩放（0.25–4×）、空格/中键/右键拖拽平移、框选、Delete 删除

## 后台排期规则

- 同场地 + 同日期 + 时段重叠即冲突，提交被拦截，弹窗列出撞在一起的两个节目
- 时段首尾相接（如 19:30–20:30 与 20:30–21:30）不算冲突
- 通过后状态变 `scheduled`，统计各剧目场次与编排时长（取节拍标注的最大 mm:ss）

## 目录结构

```
src/
├─ lib/
│  ├─ geometry.js   贝塞尔采样、轮廓展开、镜像、命中、节点插入
│  ├─ boolean.js    GH 布尔运算 + 重叠节点合并
│  ├─ pathbuild.js  圆角/平滑轮廓指令（Pixi 与 SVG 共用）
│  ├─ snap.js       四种吸附与参考线
│  ├─ svg.js        三层分组 SVG 导出
│  └─ library.js    内置机器人型号与素材持久化
├─ store/store.js   响应式状态、撤销栈、布尔提交、镜像、排期冲突、统计
├─ components/StageCanvas.vue  Pixi 画布与全部交互状态机
└─ views/           ShowsView / CanvasView / LibraryView / AdminView
```
